🛒 Carrito de Compras - Java MVC
Aplicación web dinámica con patrón MVC, Singleton y sesiones HTTP

🎯 Descripción
Carrito de compras desarrollado en Java 17 con arquitectura MVC. Los datos persisten exclusivamente en sesión HTTP mediante el patrón Singleton, permitiendo una experiencia de compra sin necesidad de base de datos. Ideal para demostrar manejo de estado en aplicaciones web.

⚙️ Tecnologías
Java 17

Servlets & JSP (javax.servlet)

Apache Tomcat 9

HTML5, CSS3, JavaScript

Eclipse IDE

Git & GitHub


🚀 Cómo probarlo

# Clonar
git clone https://github.com/tu-usuario/proyecto-carrito.git

# Importar en Eclipse como Dynamic Web Project
# Configurar Tomcat 9 y ejecutar en servidor

URL: http://localhost:8080/proyecto-carrito/

Datos: No requiere instalación de BD. Todo funciona en memoria con sesiones HTTP.
